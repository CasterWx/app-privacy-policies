隐私政策

生效与更新日期: 2026-11-13
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 应用「星幕剧场：小丑牌」（Starveil Theatre）。它说明游戏在设备上保存什么、购买与主动分享如何处理，以及你如何管理自己的信息。

游戏无需注册开发者账号。角色、牌局和工坊作品保存在本机；当前没有开发者云存档、广告或行为追踪。购买由 Apple 处理，分享由你主动发起。

1. 本地游戏数据

游戏在设备上保存角色名称、本地角色标识、成长与解锁、进行中的牌局、历史纪录、工坊方案与自制小丑能力，以及语言、声音、触感和外观等设置。这些信息用于续玩、角色隔离、创作和保留你的偏好，不会由游戏自动上传到开发者服务器。

应用使用本机存储及系统偏好设置。部分设置恢复操作会在本机保留损坏设置的副本以便恢复；这些副本不会自动发送给开发者。当前不提供开发者账号、联网排行榜或跨设备云存档。

2. 购买与恢复

免费下载包含可重复游玩的试玩内容。一次非消耗型应用内购买可开放完整玩法资格。购买、付款和恢复由 Apple 的 App Store / StoreKit 服务处理；应用读取并验证购买权益，以决定是否开放完整体验，并处理购买、恢复或撤销状态。

开发者不会通过游戏取得银行卡资料或 Apple 账户密码，也不会把支付收据或交易编号写入角色存档。Apple 可能按其服务规则处理购买和账户数据，并向开发者提供销售及财务报告。恢复购买只恢复有效权益，不会同步角色、牌局或作品。Apple 的数据处理适用其隐私政策：https://www.apple.com/legal/privacy/。

3. 工坊导入与主动分享

导入方案码在设备上解析。导出或分享由你主动操作，内容为当前作品的名称、自制卡牌名称、关卡、种子、规则和能力参数；不自动附带本地角色档案、成长记录或进行中的牌局。

作品中的文字由你填写。如果你在名称等字段中写入个人信息，这些文字会随作品一起分享。分享前请检查内容。系统分享面板把你选择的内容交给所选应用或接收者，其后续处理适用对方的规则。本应用没有公开作品社区，也不会把作品自动发布到网络。

4. 问题反馈与技术支持

打开帮助或反馈页面不会自动发送报告。你可以填写问题描述，并在发送前看到应用版本、构建号、系统、声音与触感开关、试玩或购买权益状态的摘要。只有你主动选择分享方式后，这些摘要和填写的描述才会交给所选应用；报告不自动附带存档、角色名、交易编号、支付凭据或完整日志。

如果你通过技术支持渠道联系开发者，我们会处理你主动提供的描述、附件及回复所需的联系方式，用于回答问题、排查故障或处理隐私请求。请勿发送密码、完整支付信息或无关的个人信息。相关通信仅在处理请求、维护必要的支持记录或履行法律义务所需期间保留；不再需要时予以删除或去除个人信息。

5. 第三方服务、权限与诊断

当前应用没有集成广告、跨应用追踪或第三方行为分析服务，不出售个人信息。核心游戏不需要通讯录、相机、麦克风或精确位置权限。

Apple 可能根据设备设置和自身政策处理 App Store、系统诊断及分析信息，并向开发者提供相应报告。开发者可能使用 Apple 提供的报告了解稳定性和性能；游戏没有自行部署的远程崩溃上报服务。

本隐私网页由 GitHub Pages 托管，不含广告、分析脚本、嵌入式第三方字体或我们设置的 Cookie。访问网页时，GitHub 可能为提供和保护服务处理 IP 地址、浏览器信息及请求日志，适用 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。访问技术支持网站或使用其他分享应用时，适用相应服务的隐私规则。

6. 保存、删除与备份

本地游戏数据保留在应用的设备存储中，供后续游玩和创作使用。你可以在工坊删除不再需要的作品；已开始的牌局可能保留独立的规则快照。

在系统中删除应用会移除其设备内数据；仅「卸载 App / Offload App」可能保留文稿与数据。系统备份是否保留或恢复这些内容取决于你的 Apple 设备和备份设置。开发者无法从服务器找回本地牌局或代为删除你设备上的数据。删除前请导出需要保留的工坊方案。

你可以通过技术支持网址提出访问、更正或删除你主动交给开发者的信息等请求。我们会依据适用法律处理，并在必要时核实请求与信息的关联。Apple、GitHub 或分享接收方持有的数据，应通过相应服务管理或请求处理。

7. 未成年人

游戏不要求玩家为游玩提交姓名、联系方式或生日。未成年人应在监护人指导下使用购买、分享及外部联系功能。如果你认为未成年人向开发者提供了不必要的个人信息，请通过技术支持渠道联系，以便核查和处理。

8. 更新与联系

新增在线功能、第三方服务或改变数据处理方式时，我们会更新本政策并标明日期；如适用法律要求，将另行通知或征求同意。

有关本应用的信息处理或隐私请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并说明涉及「星幕剧场」。请不要在公开 GitHub Issue 中提交存档、购买凭据或其他个人信息。
