隱私權政策

生效與更新日期: 2026-11-13
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS / iPadOS 應用程式「星幕劇場：小丑牌」（Starveil Theatre）。它說明遊戲在裝置上儲存什麼、購買與主動分享如何處理，以及你如何管理自己的資訊。

遊戲無須註冊開發者帳號。角色、牌局和工坊作品儲存在本機；目前沒有開發者雲端存檔、廣告或行為追蹤。購買由 Apple 處理，分享由你主動發起。

1. 本機遊戲資料

遊戲在裝置上儲存角色名稱、本機角色識別碼、成長與解鎖、進行中的牌局、歷史紀錄、工坊方案與自製小丑能力，以及語言、聲音、觸覺回饋和外觀等設定。這些資訊用於接續遊玩、角色隔離、創作和保留你的偏好，不會由遊戲自動上傳至開發者伺服器。

應用程式使用本機儲存及系統偏好設定。部分設定復原操作會在本機保留損壞設定的副本以便復原；這些副本不會自動傳送給開發者。目前不提供開發者帳號、連線排行榜或跨裝置雲端存檔。

2. 購買與回復

免費下載包含可重複遊玩的試玩內容。一次非消耗型 App 內購買可開放完整玩法資格。購買、付款和回復由 Apple 的 App Store / StoreKit 服務處理；應用程式讀取並驗證購買權益，以決定是否開放完整體驗，並處理購買、回復或撤銷狀態。

開發者不會透過遊戲取得付款卡資料或 Apple 帳號密碼，也不會將付款收據或交易編號寫入角色存檔。Apple 可能依其服務規則處理購買和帳號資料，並向開發者提供銷售及財務報告。回復購買只回復有效權益，不會同步角色、牌局或作品。Apple 服務適用其隱私權政策：https://www.apple.com/legal/privacy/。

3. 工坊匯入與主動分享

匯入方案碼在裝置上解析。匯出或分享由你主動操作，內容為目前作品的名稱、自製卡牌名稱、關卡、種子、規則和能力參數；不自動附帶本機角色檔案、成長紀錄或進行中的牌局。

作品中的文字由你填寫。如果你在名稱等欄位寫入個人資訊，這些文字會隨作品一起分享。分享前請檢查內容。系統分享面板將你選擇的內容交給所選應用程式或接收者，其後續處理適用對方的規則。本遊戲沒有公開作品社群，也不會自動將作品發佈至網路。

4. 問題回報與技術支援

開啟說明或問題回報頁面不會自動傳送報告。你可以填寫問題描述，並在傳送前看到應用程式版本、建置編號、系統、聲音與觸覺回饋開關、試玩或購買權益狀態的摘要。只有你主動選擇分享方式後，這些摘要和填寫的描述才會交給所選應用程式；報告不自動附帶存檔、角色名、交易編號、付款憑據或完整記錄檔。

如果你透過技術支援管道聯絡開發者，我們會處理你主動提供的描述、附件及回覆所需的聯絡資訊，用於回答問題、排查故障或處理隱私請求。請勿傳送密碼、完整付款資訊或無關的個人資訊。相關通信僅在處理請求、維護必要的支援紀錄或履行法律義務所需期間保留；不再需要時予以刪除或移除個人資訊。

5. 第三方服務、權限與診斷

目前應用程式沒有整合廣告、跨應用程式追蹤或第三方行為分析服務，不出售個人資訊。核心遊戲不需要聯絡人、相機、麥克風或精確位置權限。

Apple 可能依據裝置設定和自身政策處理 App Store、系統診斷及分析資訊，並向開發者提供相關報告。開發者可能使用 Apple 提供的報告了解穩定性和效能；遊戲沒有自行部署的遠端當機回報服務。

本隱私網頁由 GitHub Pages 託管，不含廣告、分析指令碼、嵌入式第三方字型或我們設定的 Cookie。造訪網頁時，GitHub 可能為提供和保護服務處理 IP 位址、瀏覽器資訊及請求記錄，適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。造訪技術支援網站或使用其他分享應用程式時，適用相應服務的隱私規則。

6. 保留、刪除與備份

本機遊戲資料保留於應用程式的裝置儲存空間，供後續遊玩和創作使用。你可以在工坊刪除不再需要的作品；已開始的牌局可能保留獨立的規則快照。

在系統中刪除 App 會移除其裝置內資料；僅「卸載 App / Offload App」可能保留文件與資料。系統備份是否保留或復原這些內容取決於你的 Apple 裝置和備份設定。開發者無法從伺服器找回本機牌局，或代為刪除你裝置上的資料。刪除前請匯出需要保留的工坊方案。

你可以透過技術支援網址提出存取、更正或刪除你主動交給開發者的資訊等請求。我們會依據適用法律處理，並在必要時核實請求與資訊的關聯。Apple、GitHub 或分享接收方持有的資料，應透過相應服務管理或提出請求。

7. 未成年人

遊戲不要求玩家為遊玩提交姓名、聯絡資訊或生日。未成年人應在監護人指導下使用購買、分享及對外聯絡功能。如果你認為未成年人向開發者提供了不必要的個人資訊，請透過技術支援管道聯絡，以便查核和處理。

8. 更新與聯絡

新增連線功能、第三方服務或改變資料處理方式時，我們會更新本政策並標示日期；如適用法律要求，將另行通知或徵求同意。

有關本應用程式的資訊處理或隱私請求，請透過技術支援網址 https://ai-topic.cn 聯絡開發者 Wang xiaohu，並說明涉及「星幕劇場」。請勿在公開 GitHub Issue 提交存檔、購買憑據或其他個人資訊。
