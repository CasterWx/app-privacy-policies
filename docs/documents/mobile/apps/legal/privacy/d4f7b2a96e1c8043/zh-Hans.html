隐私政策

生效与更新日期: 2026-11-26
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 应用「每周一格 · LifeWeeks」（含锁屏与桌面小组件、Apple 快捷指令与 Siri 语音操作）。本政策说明应用如何在设备本地及可选的个人 iCloud 私有空间中保存你的周记、照片与人生画册，各项系统权限如何仅在端侧使用，以及你如何随时完整导出或永久删除数据。

无需注册账号。你记录的出生日期、人生画册、周记文字、心情色块、时空胶囊、章节与照片均仅保存在你的设备本地及你个人 Apple ID 下的 iCloud 私有空间中。开发者没有自建内容服务器，无法查看、收集或出售你的日记数据，应用亦不含任何第三方广告、统计或跨应用追踪 SDK。

1. 本地数据存储与个人 iCloud 私有同步

你在应用内填写的出生日期、预期跨度、多本画册配置、每周标题与正文、情绪标记、地点文字、人生章节、时空胶囊以及附加照片（端侧压缩后外置存储）均保存在本机 SwiftData 数据库与 UserDefaults 中，并通过 App Group 仅向本应用自带的桌面与锁屏小组件共享轻量展示快照（不含敏感账户信息）。

当你开启 iCloud 同步且设备已登录个人 Apple ID 时，系统会通过 Apple CloudKit 私有数据库在你的 Apple 设备间自动同步上述数据。该私有空间完全由你的 Apple 账户控制，开发者无权访问、检索或解密你的内容；适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

2. 相册、麦克风、语音识别与生物识别权限

照片库权限仅用于在你主动编辑周记或使用「相册时光机」时，在设备本地按周次筛选推荐照片及保存你挑选的配图；「仅添加照片」权限仅用于将你主动生成的 3× 艺术画报与分享卡片保存至系统相册。应用绝不会在后台上传你的相册内容。

麦克风与语音识别权限仅在你主动点击「30 秒语音速记」时调用 Apple 系统语音识别能力将口述实时转为文字，应用不会保存原始录音文件，也不会将音频发送至开发者服务器。面容 ID / 触控 ID 隐私锁仅调用系统 LocalAuthentication 框架在设备本地解锁，应用绝不读取或存储任何生物特征数据。

3. 离线洞察、本地提醒与快捷指令

年度关键词词云与情绪复盘统计 100% 在你的设备本地通过 Apple NaturalLanguage 框架完成分词与聚合，不调用任何外部 AI 接口。

每周温柔提醒与时空胶囊解封提醒均由 iOS 本地通知中心（UNUserNotificationCenter）在设备端调度触发，不依赖远程推送服务器。Apple 快捷指令与 Siri 操作同样仅在设备本地唤起应用。

4. 数据主权、主动导出与分享

你可以随时在「设置 → 备份、导出与演示」中一键导出开放格式的「Markdown + 照片 (.zip)」完整备份归档，或在 Pro 模式下生成可打印的矢量 PDF 编年史及 3× 高清艺术画报。所有导出文件均在设备本地生成，仅当你主动通过系统分享面板发送给其他应用或保存至网盘时才离开应用；后续处理适用接收方的隐私规则。

5. 内购订阅、终身买断与恢复购买

核心四千周网格、每周文字/心情记录、单图记录与 Markdown ZIP 完整备份/恢复永久免费。每周一格 Pro 提供一次性终身买断（非消耗型）与年度自动续期订阅，用于解锁每周最多 4 张照片、无限人生章节、多本画册、精选纸面主题与可打印矢量 PDF 编年史等收藏级体验。

所有付款、订阅续期、家人共享、恢复购买与退款校验均由 Apple App Store / StoreKit 2 处理。开发者不接触你的银行卡号或 Apple 账户密码；Apple 可能按其规则向开发者提供匿名交易汇总统计，适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

6. 零第三方追踪、数据删除与联系方式

每周一格不集成任何第三方广告网络、行为分析埋点或跨应用追踪 SDK，亦不出售个人信息。Apple 可能根据你的系统「分析与改进」设置向开发者提供匿名崩溃与性能诊断报告。本隐私网页托管于 GitHub Pages，不含广告、分析脚本或我们设置的 Cookie；访问网页时 GitHub 可能记录基础安全请求日志，适用 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

你随时可在应用「设置 → 备份、导出与演示」中点击「清空本地全部记录」一键删除全部周记与章节，或卸载应用并管理 iCloud 存储空间以彻底清除数据。如有任何隐私疑问或请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「每周一格 LifeWeeks」（请勿在咨询中发送个人日记备份文件或支付凭据）。
