隱私權政策

生效與更新日期: 2026-11-26
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS / iPadOS 應用程式「每週一格 · LifeWeeks」（含鎖定畫面與主畫面小工具、Apple 捷徑與 Siri 操作）。本政策說明應用程式如何在裝置本機及選用的個人 iCloud 私有空間中保存你的週記、照片與人生畫冊，以及你如何隨時匯出或永久刪除資料。

無須註冊帳號。你記錄的出生日期、人生畫冊、週記文字、心情色塊、時空膠囊、章節與照片皆僅保存於你的裝置本機及你個人 Apple ID 的 iCloud 私有空間中。開發者未架設內容伺服器，絕不讀取、蒐集或販售你的個人日記資料，且不含任何第三方廣告或跨 App 追蹤 SDK。

1. 本機資料儲存與個人 iCloud 私有同步

你在應用程式內輸入的出生日期、網格跨度、多本畫冊設定、每週標題與內文、情緒標記、地點文字、人生章節、時空膠囊及附加照片，皆儲存在裝置本機的 SwiftData 資料庫與 UserDefaults 中，並僅透過 App Group 向本應用隨附的小工具提供輕量顯示快照。

當你啟用 iCloud 同步且裝置已登入個人 Apple ID 時，系統會透過 Apple CloudKit 私有資料庫在你的 Apple 裝置間自動同步。開發者無法存取或檢視你的私有資料庫，適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

2. 相簿、麥克風、語音辨識與生物辨識權限

照片圖庫權限僅供你在編輯週記或使用「相簿時光機」時於裝置本機按週次篩選推薦照片；僅加入照片權限僅供儲存你主動產生的 3× 藝術海報與分享卡片，絕不在背景上傳相簿。

麥克風與語音辨識權限僅於你啟動「30 秒語音速記」時呼叫 Apple 語音辨識即時轉為文字，不保存錄音檔亦不上傳至開發者伺服器。Face ID / Touch ID 隱私鎖僅透過系統 LocalAuthentication 框架於本機解鎖，應用程式絕不存取任何生物特徵資料。

3. 離線洞察、本機提醒與捷徑

年度關鍵字詞雲與情緒統計 100% 於裝置端透過 Apple NaturalLanguage 框架完成計算，不呼叫任何外部 AI 服務。

每週提醒與時空膠囊解封通知皆由 iOS 本機通知中心（UNUserNotificationCenter）於裝置端排程觸發，無需遠端推播伺服器；Apple 捷徑與 Siri 亦僅於本機執行。

4. 資料主權與主動匯出

你隨時可在「設定 → 備份、匯出與示範」一鍵匯出開放格式的「Markdown + 照片 (.zip)」完整備份，或於 Pro 模式產生可列印的向量 PDF 編年史與 3× 高清海報。所有檔案皆在本機生成，僅於你主動透過系統分享面板傳送時才離開應用程式。

5. 訂閱、終身買斷與回復購買

核心四千週網格、每週文字/心情記錄、單張配圖與 Markdown ZIP 完整備份/還原永久免費。每週一格 Pro 提供一次性終身買斷（非消耗型）與年度自動續期訂閱，用於解鎖每週最多 4 張照片、無限章節、多本畫冊、精選紙面主題與可列印向量 PDF 編年史。

所有付款、續訂管理、家人共享、回復購買與退款驗證皆由 Apple App Store / StoreKit 2 處理，開發者不接觸付款卡資訊或 Apple 帳號密碼，適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

6. 零第三方追蹤、資料刪除與聯絡方式

每週一格不含任何第三方廣告網路、行為分析 SDK 或跨 App 追蹤工具，不販售個人資料。本隱私網頁託管於 GitHub Pages，不含廣告、指令碼或我們設定的 Cookie；連線紀錄適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

你隨時可在「設定 → 備份、匯出與示範」點擊「清空本機全部記錄」永久刪除本機資料，或解除安裝應用程式並管理 iCloud 空間以清除同步備份。如有任何隱私疑問，請透過 https://ai-topic.cn 聯絡開發者 Wang xiaohu，並註明涉及「每週一格 LifeWeeks」。
