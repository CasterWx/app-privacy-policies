偷得半页闲

隐私政策

生效与更新日期: 2026-11-26
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 本地电子书阅读应用「偷得半页闲」（含系统分享扩展「存入半页闲」及主屏幕桌面小组件）。本政策说明应用如何在设备本地解析与存储你的电子书、自定义字体、阅读进度与朱批笔记，局域网 Wi-Fi 传书与个人 iCloud 键值同步如何工作，应用内购买如何处理，以及你如何管理或删除全部数据。

无需注册账号，不含任何书源或书城。所有电子书（EPUB、TXT、Markdown、PDF）与字体均保存在你的设备本地并离线解析排版；开发者不运营书籍或用户服务器，不上传、不收集、不出售你的藏书与阅读记录，亦不含广告或跨应用追踪。

1. 本地书籍、自定义字体导入与分享扩展

当你通过系统「文件」选择器、隔空投送（AirDrop）或系统分享扩展「存入半页闲」主动导入本地电子书（EPUB、TXT、Markdown、PDF）或自定义字体文件（TTF、OTF、TTC）时，应用仅在你的设备本地沙盒及共享应用组（App Group）目录中复制、解析并渲染这些文件。

全部解析、中文排版、听书语音合成（基于系统 AVSpeechSynthesizer）及离线网页视图渲染均在设备本地运行，电子书原文、阅读记录与笔记不会上传至开发者服务器。

2. 局域网 Wi-Fi 传书权限

仅当你主动打开「局域网 Wi-Fi 传书」页面时，应用才会请求 iOS 本地网络权限，并在你当前连接的同一局域网内启动临时本地 HTTP 传书服务，方便你通过电脑浏览器将本地电子书或字体文件直接传送至手机。

传输流量仅在你自己的局域网设备之间直接流转，不经过任何外部云端或开发者服务器；关闭传书页面后本地服务立即停止。

3. 相册写入与自定义封面选取

仅当你在「画卷书摘工坊」中主动点击「存入相册」时，应用才会请求系统照片图库写入权限，用于将你生成的书摘长图保存至本地相册。

当你使用系统照片选择器为书籍更换自定义封面时，应用仅读取你主动选定的单张图片并保存在本地书房封面目录中，不访问你的整个相册库。

4. 桌面小组件、个人 iCloud 同步与 JSON 备份

应用在设备本地及共享应用组（App Group）中保存阅读偏好、书签、朱批划线、阅读时长统计以及桌面小组件（「案头在读」「每日素笺」）所需的最小展示快照。

应用支持使用 Apple 系统提供的个人 iCloud 键值存储（NSUbiquitousKeyValueStore）在你自己的 iPhone 与 iPad 之间同步阅读进度（按文件哈希匹配）与私人藏书印文。这些数据仅保存在你个人的 Apple 账户 iCloud 空间内，不经过开发者服务器，开发者无法访问。你也可以在「书房雅设」中随时将书签、朱批与进度导出为便携 JSON 备份文件自行保管或恢复。

5. 购买与恢复

应用提供可选的一次性非消耗型应用内购买「偷得半页闲 · 雅藏版 Pro（永久买断）」，绝无自动续费订阅与广告。

所有付款、权益验证、恢复购买与退款状态核验均由 Apple App Store / StoreKit 2 处理。开发者不会获取你的银行卡信息或 Apple 账户密码。Apple 的商业服务与匿名财务统计适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

6. 主动分享、保留、删除与联系

当你主动将画卷书摘长图、Markdown 读书笔记或 JSON 备份文件分享给第三方应用或他人时，后续处理适用接收方的隐私规则。本应用不集成广告 SDK、行为分析埋点或跨应用追踪框架，不出售个人信息。本隐私网页托管于 GitHub Pages，不含广告、脚本或我们设置的 Cookie；GitHub 的基础访问日志适用 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

你的藏书、字体、朱批笔记与设置全部保留在你的设备存储与个人 iCloud 空间内；在应用内移出书籍或从系统卸载应用即可清除设备上的本地数据。开发者没有服务器端副本，无法代你访问或找回本地数据。如有隐私疑问或请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「偷得半页闲」。
