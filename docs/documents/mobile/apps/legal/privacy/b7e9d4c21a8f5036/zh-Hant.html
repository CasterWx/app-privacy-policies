偷得半頁閒

隱私權政策

生效與更新日期: 2026-11-26
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS / iPadOS 本機電子書閱讀應用程式「偷得半頁閒」（含系統分享延伸功能與主畫面小工具）。本政策說明應用程式如何在裝置本機處理你匯入的電子書、自訂字體、閱讀進度與批註筆記，以及區域網路傳書、個人 iCloud 同步與購買之運作方式。

無須註冊帳號，不含任何書城或書源。所有電子書（EPUB、TXT、Markdown、PDF）與字體皆於你的裝置本機離線解析與排版；開發者不營運書籍伺服器，不上傳、不蒐集、不販售你的藏書與閱讀紀錄，亦不含廣告或跨 App 追蹤。

1. 本機書籍、自訂字體匯入與分享延伸功能

當你透過系統檔案選擇器、AirDrop 或系統分享延伸功能匯入電子書（EPUB、TXT、Markdown、PDF）或字體檔（TTF、OTF、TTC）時，應用程式僅在你的裝置本機沙盒及 App Group 共享容器內解析與渲染。

全部排版、語音朗讀與離線檢視皆於本機完成，絕不會將電子書原文或筆記上傳至開發者伺服器。

2. 區域網路 Wi-Fi 傳書權限

僅當你主動開啟「Wi-Fi 傳書」畫面時，應用程式才會要求本機網路權限並於同一區域網路啟動暫時性本機 HTTP 傳書服務，方便從電腦瀏覽器直接傳送書籍或字體；關閉畫面即立即停止服務，資料不經過外部雲端。

3. 相簿寫入與自訂封面選取

僅當你於「畫卷書摘工坊」點擊儲存長圖時，應用程式才會要求相簿寫入權限；透過系統照片選擇器更換自訂書籍封面時，僅讀取你選取的單張圖片並儲存在本機。

4. 桌面小工具、個人 iCloud 同步與 JSON 備份

應用程式於本機及 App Group 儲存閱讀偏好、書籤、朱批劃線、閱讀統計與主畫面小工具摘要。

應用程式支援使用 Apple 個人 iCloud 鍵值儲存（NSUbiquitousKeyValueStore）在你的 iPhone 與 iPad 之間同步閱讀進度與私人藏書印文，資料僅存於你個人的 iCloud 帳號，開發者無法存取。你亦可隨時匯出或還原 JSON 備份檔。

5. 購買與回復

應用程式提供選用的一次性買斷 App 內購買（雅藏版 Pro），無訂閱且無廣告。所有付款、驗證與回復購買皆由 Apple App Store / StoreKit 2 處理，適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

6. 分享、刪除與聯絡

本應用程式不含廣告 SDK、行為分析或跨 App 追蹤，不販售個人資料。本網頁託管於 GitHub Pages，適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

刪除書籍或移除應用程式即可清除本機資料。如有任何隱私疑問，請透過 https://ai-topic.cn 聯絡開發者 Wang xiaohu，並註明涉及「偷得半頁閒」。
