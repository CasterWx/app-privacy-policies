隱私權政策

生效與更新日期: 2026-11-28
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 Apple 平台應用程式「StudioPulse」（Bundle ID：com.xiaohuwang.StudioPulseApp，支援 iOS / iPadOS / macOS，含桌面與鎖定畫面小工具延伸功能）。本政策依據應用程式實際程式碼資料流，如實說明 App Store Connect 金鑰與營收資料的本機處理方式、選用零留存即時推播中繼、選用自託管模式、應用程式內購買以及你的資料控制權。

採用純端側 BYOK（自帶金鑰）架構，無需註冊開發者帳號。你的 App Store Connect .p8 私鑰、Key ID、Issuer ID 與供應商編號僅儲存於裝置系統鑰匙圈（Keychain），絕不上傳至開發者伺服器；所有銷售、訂閱、榜單與評論快取皆保留於裝置本機。選用的即時推播中繼採零留存盲轉設計，不接觸私鑰、不儲存交易紀錄。零廣告、零第三方分析 SDK、零跨 App 追蹤。

1. 純端側 BYOK 架構與本機資料儲存

StudioPulse 預設以純本機直連模式運作。你匯入的 App Store Connect API 憑證（Key ID、Issuer ID、.p8 私鑰內容、供應商編號）以及選用的中繼管理金鑰或自託管權杖，均僅加密保存於裝置系統鑰匙圈（Keychain，僅限本裝置首次解鎖後存取並依工作室設定隔離），絕不會上傳至開發者伺服器。

ES256 JWT 簽章完全於裝置本機透過 Apple CryptoKit 運算完成。應用程式直接由你的裝置連線至 Apple 官方 App Store Connect REST API（api.appstoreconnect.apple.com）、Apple 公開 iTunes Lookup / Search / RSS 榜單介面（itunes.apple.com）及公開匯率介面（open.er-api.com，僅用於取得公開多幣別參考匯率），不經開發者伺服器中轉。

下載的銷售報表、訂閱摘要與事件、榜單歷史、使用者評論快取、工作室設定與小工具快照，均嚴格留存於你的裝置沙盒與 Apple 私有 App Group 容器（group.com.xiaohuwang.studiopulse.app），以供主程式與小工具延伸功能同步顯示。背景巡檢（BGAppRefreshTask）與本機通知（UNUserNotificationCenter）亦皆於裝置本機執行。

2. 選用「零留存即時推播中繼」服務

即時推播功能預設關閉，僅在你主動啟用並開通專屬推播路由時，應用程式才會連線至官方零留存推播中繼服務（studiopulse-relay.studio-payment-hub.workers.dev，部署於 Cloudflare Workers 與 D1）。

該中繼服務僅儲存訊息轉發所需的最小路由設定：隨機產生的租戶路由 ID 與不可猜測之 Webhook 權杖、管理金鑰的 SHA-256 雜湊值（不存明文）、工作室顯示名稱、選用的 APNs 裝置推播權杖、你主動設定的外部 Webhook 通知網址與簽章密鑰（如飛書、釘釘、企業微信、Bark、Slack、Discord 或通用 HTTPS Webhook），以及基本轉發計數、最近事件時間戳與短週期限流計數。

中繼服務絕不要求或接觸你的 .p8 私鑰，亦絕不於資料庫中儲存任何交易金額、訂單編號或銷售明細。當 Apple 向你的專屬路由傳送 App Store 伺服器通知（ASSN V2）時，中繼僅於記憶體內依據 Apple Root CA - G3 驗證 JWS 簽章，轉發通知至你的接收管道或 APNs 後即刻捨棄原始交易資料。你隨時可在應用程式內輪換 Webhook 網址，或一鍵註銷並永久刪除雲端推播路由。

3. 選用自託管雲端模式

若你於設定中主動切換至「自託管雲端」模式，應用程式僅會連線至你自己提供的伺服器網址與存取權杖。自託管伺服器的資料處理由你的自有部署自行管理，開發者無法存取。

4. 應用程式內購買與訂閱（StudioPulse Pro）

StudioPulse 透過 Apple StoreKit 2 提供選用的「StudioPulse Pro」方案（包含月付訂閱、年付訂閱與一次性終身買斷）。所有付款、驗證、恢復購買與退款或撤銷同步皆由 Apple App Store 獨家處理，開發者不會取得你的付款卡資訊或 Apple 帳號密碼。

Apple 依其隱私權政策處理交易，並可能向開發者（Wang xiaohu）提供標準的 App Store 伺服器通知（ASSN V2）與彙總銷售報告，詳見 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

5. 版本檢查、原生評分、零廣告與零追蹤

為提醒新版本發佈，應用程式於聯網狀態下至多每 24 小時一次（或手動點擊檢查更新時）向 Apple 公開介面（itunes.apple.com/lookup）查詢版本資訊，僅傳送 Bundle ID 與地區代碼，不含任何個人或營收資料。原生評分視窗（AppStore.requestReview）由 Apple 直接處理。

StudioPulse 不整合任何第三方廣告 SDK、統計分析 SDK 或跨 App 追蹤框架（NSPrivacyTracking = false），絕不販售或分享個人資料。Apple 可能依你的裝置診斷設定提供匿名彙總之當機與效能報告。

本隱私權網頁託管於 GitHub Pages，不含廣告、統計指令碼或我們設定的 Cookie；連線紀錄適用 GitHub 隱私權聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. 資料保存、刪除與聯絡我們

所有本機金鑰、銷售帳本、榜單歷史、評論快取與小工具資料皆僅保存於你的裝置本機。你隨時可在應用程式內刪除工作室設定、註銷並刪除選用的雲端推播路由，或解除安裝應用程式以移除全部本機資料。
