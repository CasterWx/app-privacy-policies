プライバシーポリシー

発効・更新日: 2026-11-28
開発者: Wang xiaohu

本ポリシーは、Wang xiaohu が提供する Apple プラットフォーム向けアプリ「StudioPulse」（Bundle ID：com.xiaohuwang.StudioPulseApp、iOS / iPadOS / macOS 対応、ホーム画面およびロック画面ウィジェット拡張機能を含む）に適用されます。実際のコード上のデータフローに基づき、App Store Connect 認証情報や売上データの端末内処理、任意のゼロ保持リアルタイムプッシュ中継、任意のセルフホストモード、アプリ内課金、およびデータ管理方法について透明にご説明します。

開発者アカウント登録不要の純粋な端末内 BYOK（自己鍵管理）アーキテクチャを採用しています。App Store Connect の .p8 秘密鍵、Key ID、Issuer ID、ベンダー番号は端末のシステムキーチェーン（Keychain）のみに保存され、開発者サーバーへ送信されることは一切ありません。売上・サブスクリプション・ランキング・レビューのキャッシュもすべて端末内に留まります。任意のプッシュ中継はゼロ保持設計であり、秘密鍵へアクセスせず取引履歴も保存しません。広告、第三者解析 SDK、クロスアプリ追跡は一切ありません。

1. 純粋な端末内 BYOK アーキテクチャとローカル保存

StudioPulse はデフォルトで純粋な端末内ダイレクト接続モードで動作します。お客様が設定した App Store Connect API 認証情報（Key ID、Issuer ID、.p8 秘密鍵 PEM、ベンダー番号）および任意の中継管理シークレットやセルフホスト用トークンは、端末のシステムキーチェーン（Keychain、当該端末の初回ロック解除後のみアクセス可能、スタジオプロファイル単位で分離）にのみ暗号化保存され、開発者サーバーへ送信されることはありません。

ES256 JWT 署名は Apple CryptoKit を用いて端末内のみで生成されます。通信はお客様の端末から Apple 公式の App Store Connect REST API（api.appstoreconnect.apple.com）、Apple 公開の iTunes Lookup / Search / RSS ランキングエンドポイント（itunes.apple.com）、および公開為替レート API（open.er-api.com、複数通貨の参考換算のみに使用）へ直接行われます。

取得した売上レポート、サブスクリプション集計・イベント、ランキング推移、カスタマーレビューキャッシュ、スタジオ設定およびウィジェット用スナップショットは、端末内のアプリサンドボックスおよび Apple のプライベート App Group コンテナ（group.com.xiaohuwang.studiopulse.app）のみに保存され、本体アプリとウィジェット拡張機能間で同期されます。任意のバックグラウンド巡回（BGAppRefreshTask）や審査状況・ランキング変動・低評価レビューのローカル通知（UNUserNotificationCenter）もすべて端末内で完結します。

2. 任意の「ゼロ保持リアルタイムプッシュ中継」サービス

リアルタイムプッシュ通知は初期状態で無効となっており、お客様が明示的に有効化して専用ルートを開設した場合にのみ、公式のゼロ保持プッシュ中継サービス（studiopulse-relay.studio-payment-hub.workers.dev、Cloudflare Workers および D1 上で稼働）へ接続します。

本中継サービスが保持するのは通知転送に必要な最小限のルーティング設定のみです：ランダム生成されたテナントルート ID と推測不能な Webhook トークン、管理シークレットの SHA-256 ハッシュ（平文は保存しません）、表示用スタジオ名、任意の APNs デバイストークン（iOS プッシュ通知有効時）、お客様が指定した外部 Webhook 送信先 URL と署名シークレット（Feishu、DingTalk、WeCom、Bark、Slack、Discord、汎用 HTTPS Webhook 等）、ならびに不正利用防止のための基本稼働カウンター（転送回数、最終イベント時刻）および短時間レート制限カウンターです。

本中継サービスは .p8 秘密鍵を一切要求・参照せず、売上金額・注文 ID・顧客情報・販売台帳などの財務データを一切保存しません。Apple から専用ルートへ App Store サーバー通知（ASSN V2）が届いた際、中継はメモリ上で Apple Root CA - G3 に照らして JWS 署名を検証し、通知を整形してお客様の指定チャネルや APNs へ即時転送した直後に取引ペイロードを破棄します。アプリ内からいつでも Webhook URL のローテーション、またはクラウドルートの完全削除（D1 上のルーティング情報と端末内シークレットの消去）を行えます。

3. 任意のセルフホストハブモード

設定から明示的に「セルフホスト」モードを選択した場合、本アプリはお客様自身が指定したサーバー URL と API トークンのみに接続します。セルフホストサーバー上のデータ管理はお客様ご自身の環境に委ねられ、開発者がアクセスすることはありません。

4. アプリ内課金およびサブスクリプション（StudioPulse Pro）

StudioPulse は Apple StoreKit 2 を通じて任意の「StudioPulse Pro」プラン（月額サブスクリプション、年額サブスクリプション、買い切り型ライフタイム）を提供しています。決済処理、レシート検証、購入の復元、返金・権利取消の同期はすべて Apple App Store により処理され、開発者がクレジットカード情報や Apple アカウントの認証情報を取得することはありません。

取引は Apple プライバシーポリシーに従って処理され、Apple から開発者（Wang xiaohu）へ標準の App Store サーバー通知（ASSN V2）および集計売上レポートが提供されます。詳細は Apple プライバシーポリシーをご確認ください：https://www.apple.com/legal/privacy/。

5. バージョン確認・システム評価・広告なし・追跡なし

新バージョン公開をお知らせするため、オンライン時に最大 24 時間に 1 回（またはお客様が手動でアップデート確認を実行した際）、Apple 公開エンドポイント（itunes.apple.com/lookup）へ Bundle ID と地域コードのみを送信して最新バージョンを確認する場合があります。自然な利用節目で表示される Apple ネイティブの評価ダイアログ（AppStore.requestReview）は Apple により直接処理されます。

StudioPulse には第三者広告 SDK、アナリティクス／テレメトリ SDK、クロスアプリ追跡フレームワーク（NSPrivacyTracking = false）は一切含まれておらず、個人データの販売・共有も行いません。端末の診断設定に基づき、Apple から匿名集計されたクラッシュおよびパフォーマンスレポートが提供される場合があります。

本プライバシーポリシーページは GitHub Pages 上で公開されており、広告、解析スクリプト、当方設定の Cookie は含みません。アクセス時の標準ログについては GitHub プライバシーステートメントをご確認ください：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. データの保持・削除およびお問い合わせ

すべてのローカル認証情報、売上台帳、ランキング履歴、レビューキャッシュ、ウィジェットスナップショットはお客様の端末内のみに保存されます。アプリ内からいつでもスタジオプロファイルの削除や任意のクラウドプッシュルートの解約・完全削除が可能であり、アプリを削除することですべてのローカルデータが消去されます。

プライバシーに関するご質問やサポートのご要望は、サポート URL https://ai-topic.cn より「StudioPulse」と明記のうえ開発者 Wang xiaohu までお問い合わせください。お問い合わせの際は .p8 秘密鍵や管理シークレット等の機密情報を送信しないでください。
