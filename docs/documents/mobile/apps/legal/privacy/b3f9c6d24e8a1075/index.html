隐私政策

生效与更新日期: 2026-11-28
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 Apple 平台应用「StudioPulse」（Bundle ID：com.xiaohuwang.StudioPulseApp，适用于 iOS / iPadOS / macOS，含桌面与锁屏小组件扩展）。本政策基于应用实际代码数据流，如实说明你的 App Store Connect 密钥与营收数据的端侧处理方式、可选零留存实时推送中继、可选自托管模式、应用内购买以及你的数据控制权。

采用纯端侧 BYOK（自带密钥）架构，无需注册开发者账号。你的 App Store Connect .p8 私钥、Key ID、Issuer ID 与供应商编号仅存于设备系统钥匙串（Keychain），绝不上传至开发者服务器；所有销售、订阅、榜单与评论缓存均保留在设备本地。可选的实时推送中继采用零留存盲转设计，不接触私钥、不存储任何交易记录。零广告、零第三方分析 SDK、零跨应用追踪。

1. 纯端侧 BYOK 架构与本地数据存储

StudioPulse 默认以纯本地直连模式运行。你导入的 App Store Connect API 凭据（Key ID、Issuer ID、.p8 私钥内容、供应商编号）以及可选的中继管理密钥或自托管令牌，均仅加密保存于设备系统钥匙串（Keychain，访问级别为仅限本设备首次解锁后访问，并按工作室配置隔离），绝不会上传至开发者服务器。

ES256 JWT 签名完全在你的设备本地通过 Apple CryptoKit 计算完成。应用直接由你的设备向 Apple 官方 App Store Connect REST API（api.appstoreconnect.apple.com）、Apple 公开 iTunes Lookup / Search / RSS 榜单接口（itunes.apple.com）以及公开汇率接口（open.er-api.com，仅用于拉取公开多币种参考汇率）发起请求，不经过开发者中转。

拉取到的销售报表、订阅汇总与事件、App 榜单历史、用户评论缓存、工作室配置及小组件快照，均严格保存在你的设备本地沙盒及 Apple 私有 App Group 容器（group.com.xiaohuwang.studiopulse.app）内，用于主应用与小组件扩展同步显示。你开启后台巡检与本地通知（BGAppRefreshTask / UNUserNotificationCenter）时，审核状态变动、冲榜与低星评论提醒均在设备本地计算并触发。

2. 可选「零留存实时推送中继」服务

实时推送功能默认关闭，仅在你主动开启并点击开通专属推送路由时，应用才会连接官方零留存推送中继服务（studiopulse-relay.studio-payment-hub.workers.dev，部署于 Cloudflare Workers 与 D1）。

该中继服务仅存储完成消息路由所必需的最少配置数据：随机生成的租户路由 ID 与不可猜测的 Webhook 令牌、管理密钥的 SHA-256 哈希值（不存明文）、自定义工作室显示名、可选的 Apple 远程推送设备令牌（APNs Device Token，仅在你授权推送通知后用于下发 iOS 推送）、你主动填写的外部 Webhook 通知地址与签名密钥（如飞书、钉钉、企业微信、Bark、Slack、Discord 或自定义 HTTPS Webhook），以及基础运行计数（转发次数、最近事件时间戳）和短周期限流计数（用于防止接口滥用）。

中继服务绝不索取、绝不接触你的 .p8 私钥，且绝不在数据库中持久化存储任何订单金额、商品明细、交易单号或销售流水。当 Apple 向你的专属 Webhook 地址发送 App Store 服务器通知（ASSN V2）时，中继仅在内存中依据 Apple Root CA - G3 证书链验证 JWS 签名，格式化消息并实时转发至你配置的接收渠道或 APNs 后立即丢弃原始交易数据。你可随时在应用内一键轮换 Webhook 地址，或点击「注销并删除云端推送路由」立即彻底删除云端路由记录与本地密钥。

3. 可选自托管云端模式

如果你在设置中主动切换至「自托管云端」模式，应用仅会连接你自己填写并控制的私有服务器地址与访问令牌。自托管服务器上的数据存储与处理完全由你的自有部署决定，开发者无法访问该服务器或其中的数据。

4. 应用内购买与订阅（StudioPulse Pro）

StudioPulse 提供可选的「StudioPulse Pro」应用内购买方案（包括按月订阅、按年订阅及一次性终身买断），所有支付结算、票据校验、恢复购买以及退款或权益撤销同步均由 Apple App Store 与 StoreKit 2 独家处理。开发者不会获取你的银行卡号、账单地址或 Apple 账户密码。

Apple 依据其隐私政策处理交易，并可能向开发者（Wang xiaohu）提供标准的 App Store 服务器通知（ASSN V2）及汇总销售报告，详情请参阅 Apple 隐私政策：https://www.apple.com/legal/privacy/。

5. 版本更新检测、原生评分、零广告与零追踪

为在发布新版本时提醒你升级，应用在联网状态下至多每 24 小时一次（或由你手动点击检查更新时）向 Apple 公开接口（itunes.apple.com/lookup）查询 StudioPulse 的线上版本号与商店链接，仅发送 Bundle ID 与地区代码，不含任何个人身份信息或营收数据。在达成自然使用里程碑后，应用可能调用 Apple 原生评分窗口（AppStore.requestReview），交互由 Apple 处理。

StudioPulse 不集成任何第三方广告 SDK、统计分析埋点或跨应用追踪框架（隐私清单声明 NSPrivacyTracking = false），绝不出售或共享你的个人信息。Apple 可能依据你的设备诊断与分析设置向开发者提供匿名汇总的崩溃与性能报告。

本隐私政策网页托管于 GitHub Pages，不含广告、统计脚本或我们设置的 Cookie；访问网页时 GitHub 可能记录基础服务器安全日志，详见 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. 数据保存、删除与联系我们

你的全部本地密钥、销售账本、榜单历史、评论缓存与小组件数据均保存在你自己的设备中。你可随时在应用内删除特定工作室配置、注销并彻底删除可选的云端推送路由，或直接卸载应用以清除本机全部应用数据。开发者不持有你的本地密钥或账本备份，无法访问或代为恢复。

如对本隐私政策有任何疑问或需要技术支持，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「StudioPulse」。请勿在联系内容中发送 .p8 私钥、管理密钥或其他敏感凭据。
