隐私政策

生效与更新日期: 2026-11-25
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS 应用「体迹 BodyTrace」（含 Siri 快捷指令操作）。本政策说明应用如何在设备本地记录你的症状与皮损照片、可选的 Apple HealthKit 睡眠只读关联与实时气压气象查询如何工作、应用内购买如何处理，以及你如何管理或删除自己的数据。

无需注册账号。所有症状记录、疼痛评分、诱因、用药、皮损照片及就诊报告表头均仅保存在你的 iPhone 本地数据库中；开发者不运营健康数据服务器，不上传、不出售你的个人健康信息，亦不含广告或跨应用追踪。

1. 本地健康记录与皮损照片

你在应用内主动填写的症状类型、VAS 强度评分（1–10 分）、发生时间与持续时长、疑似诱因、用药与缓解反馈、备注、每日平稳打卡、自定义诱因标签以及可选的患者就诊表头，均仅保存在你的设备本地 SwiftData 数据库与 UserDefaults 中，不会上传至开发者服务器。

当你通过 iOS 系统照片选择器（PhotosPicker）将皮损或症状辅助图片附加到单条记录时，应用仅访问你明确选定的图片并存于本机应用数据库内，不会扫描你的整个照片图库，也不会将图片发送至任何外部服务器。

2. Apple HealthKit 睡眠数据（仅只读、本地处理）

仅当你主动点击并授予系统权限后，体迹才会通过 Apple HealthKit 以只读方式读取你的睡眠分析（Sleep Analysis）样本，用于在设备本地计算个人睡眠基线与发作前夜睡眠时长，并在首页仪表盘、洞察页及你主动导出的 A4 就诊总结报告中展示睡眠关联。

体迹严格遵守 Apple HealthKit 隐私与审核规范：从 HealthKit 读取的数据绝不上传云端，绝不用于广告、营销或数据经纪，也绝不共享给任何第三方。你可以随时在 iPhone「设置 → 健康 → 数据访问与设备」中撤回权限，或在应用内改用手动补录睡眠时长。

3. 位置与实时气压气象查询

仅当你主动授予「使用 App 期间访问位置」权限后，体迹会使用设备当前的粗略经纬度向 Apple WeatherKit 查询当地实时气压、12 小时气压变化趋势、温度与湿度，用于识别变天与气压骤降等环境诱因；当 Apple WeatherKit 暂不可用时，应用会回退请求公共气象接口 Open-Meteo 获取同项实时天气数值。

经纬度仅用于当次即时气象查询，应用不会追踪、上传或保存你的历史行踪轨迹，仅在你主动保存发作记录时将对应的气压、温湿度数值随记录保存在本机。Apple Weather 服务适用 Apple 隐私政策：https://www.apple.com/legal/privacy/ 与气象归属声明：https://weatherkit.apple.com/legal-attribution.html；Open-Meteo 服务适用其条款：https://open-meteo.com/en/terms。

4. 本地提醒、快捷指令与主动导出

当你开启每晚 21:30 轻提醒或气压骤降本地预警时，所有通知均由 iOS 本地通知中心（UNUserNotificationCenter）在设备端调度生成，不依赖远程推送服务器。你也可通过 Apple 快捷指令与 Siri 在设备本地快速触发症状记录。

当你点击导出 A4 临床 PDF 就诊报告、CSV 表格或完整 JSON 本地备份时，文件全部在设备本地生成，仅在你主动通过系统分享面板或 AirPrint 隔空打印传递给你指定的对象（例如接诊医生或个人备份）时才离开应用；后续处理适用接收方的隐私规则。

5. 订阅、一次性购买与恢复

基础症状记录、今日平稳打卡与 14/30 天洞察免费使用。体迹 Pro 提供月度自动续费订阅、年度自动续费订阅（可含 7 天免费试用）以及终身买断非消耗型项目，用于解锁双语 A4 临床 PDF 导出、90 天与全周期深度洞察、气压骤降本地预警与完整备份恢复等功能。

所有付款、订阅管理、恢复购买与退款/撤销校验均由 Apple App Store / StoreKit 2 服务处理。开发者不会获取你的银行卡号或 Apple 账户密码。Apple 可能按其规则处理交易数据并向开发者提供匿名财务与统计报告，适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

6. 第三方 SDK、非医疗声明与数据删除

本应用不集成任何第三方广告 SDK、行为分析埋点或跨应用追踪框架，不出售个人信息。Apple 可能根据你的系统「分析与改进」设置向开发者提供匿名崩溃与性能诊断报告。本隐私网页由 GitHub Pages 托管，不含广告、分析脚本或我们设置的 Cookie；访问网页时 GitHub 可能记录基础安全请求日志，适用 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

体迹 BodyTrace 仅作为个人日常体征记录与就诊信息整理辅助工具，并非医疗器械，不提供医学诊断或处方建议。你随时可在应用「设置 → 数据与备份」导出完整 JSON 备份或点击「清空全部记录」一键永久删除本机数据；卸载应用亦会彻底清除全部本地数据。如有任何隐私疑问或请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「体迹 BodyTrace」（请勿在咨询中发送敏感病历原件或支付凭据）。
