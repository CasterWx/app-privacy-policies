隱私權政策

生效與更新日期: 2026-11-25
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS 應用程式「體跡 BodyTrace」（含 Apple 捷徑操作）。本政策說明應用程式如何在裝置本機記錄你的症狀與皮損照片、選用的 Apple HealthKit 睡眠唯讀關聯與即時氣壓氣象查詢運作方式，以及購買與資料管理方式。

無須註冊帳號。所有症狀紀錄、疼痛評分、誘因、用藥、皮損照片與就診報告表頭皆僅保存於你的 iPhone 本機資料庫；開發者不營運健康資料伺服器，不上傳或販售你的個人健康資訊，且不含廣告或跨 App 追蹤。

1. 本機健康紀錄與皮損照片

你在應用程式內主動填寫的症狀類型、VAS 強度評分（1–10 分）、發生時間與持續時長、疑似誘因、用藥與緩解回饋、備註、每日平穩打卡、自訂誘因標籤及選填的患者就診表頭，皆僅保存在裝置本機的 SwiftData 資料庫與 UserDefaults 中，絕不上傳至開發者伺服器。

當你透過 iOS 系統照片選擇器（PhotosPicker）附加皮損或症狀輔助圖片至單筆紀錄時，應用程式僅存取你明確選取的圖片並儲存在本機資料庫，不會掃描你的整個相簿或上傳圖片。

2. Apple HealthKit 睡眠資料（僅唯讀、本機處理）

僅在你主動點擊並授予系統權限後，體跡才會透過 Apple HealthKit 以唯讀方式存取睡眠分析（Sleep Analysis）樣本，用於在本機計算個人睡眠基線與發作前夜睡眠時長，並顯示於今日儀表板、洞察與你主動匯出的 A4 就診總結報告。

體跡嚴格遵守 Apple HealthKit 隱私規範：讀取的資料僅於本機處理，絕不上傳雲端、絕不用於廣告或行銷，也絕不分享給任何第三方。你可隨時於 iOS「設定 → 健康 → 資料取用權限與裝置」撤回授權，或於 App 內改以手動補錄睡眠時長。

3. 位置與即時氣壓氣象查詢

僅在你授予「使用 App 期間」位置權限後，體跡才會以裝置當下約略經緯度向 Apple WeatherKit 查詢當地即時氣壓、12 小時氣壓趨勢、溫度與濕度；當 WeatherKit 暫時不可用時，會回退使用公共氣象介面 Open-Meteo 取得相同即時數值。

經緯度僅供當次即時氣象查詢使用，應用程式不追蹤、不上傳也不保留你的歷史行蹤軌跡，僅在你保存發作紀錄時將對應氣象數值存入本機。Apple 服務適用其隱私權政策（https://www.apple.com/legal/privacy/）與氣象聲明（https://weatherkit.apple.com/legal-attribution.html）；Open-Meteo 適用其條款（https://open-meteo.com/en/terms）。

4. 本機提醒、捷徑與主動匯出

選用的晚間 21:30 輕提醒與氣壓驟降本機預警皆由 iOS 本機通知中心（UNUserNotificationCenter）於裝置端排程，不經遠端推播伺服器。Apple 捷徑與 Siri 語音記錄同樣於本機執行。

雙語 A4 臨床 PDF 報告、CSV 表格與 JSON 完整備份皆在本機產生，僅於你主動透過系統分享面板或 AirPrint 列印時才會交由你指定的接收方處理。

5. 訂閱、終身買斷與回復購買

基礎症狀記錄、每日平穩打卡與 14/30 天洞察免費提供。體跡 Pro 提供月度、年度（可含 7 天免費試用）自動續訂方案與一次性終身買斷，用於解鎖雙語 A4 PDF 匯出、90 天與全週期洞察、氣壓驟降本機預警及完整備份還原。

所有付款、續訂管理、回復購買與退款撤銷驗證皆由 Apple App Store / StoreKit 2 處理，開發者不接觸付款卡資料或 Apple 帳號密碼，適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

6. 第三方 SDK、非醫療聲明與資料刪除

本應用程式不含第三方廣告 SDK、行為分析追蹤器或跨 App 追蹤工具，不販售個人資料。本隱私網頁託管於 GitHub Pages，不含廣告、指令碼或我們設定的 Cookie；連線紀錄適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

體跡 BodyTrace 僅作個人日常體徵記錄與就診整理輔助工具，並非醫療器材，不提供醫學診斷或治療建議。你隨時可在「設定 → 資料與備份」匯出 JSON 備份或點擊「清空全部記錄」永久刪除本機資料，解除安裝亦會完全移除資料。如有任何隱私疑問，請透過 https://ai-topic.cn 聯絡開發者 Wang xiaohu，並註明涉及「體跡 BodyTrace」。
