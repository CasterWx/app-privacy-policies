隱私權政策

生效與更新日期: 2026-11-25
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS / iPadOS 應用程式「素框 FramePure」（含系統照片分享延伸功能與捷徑動作）。本政策說明應用程式如何在裝置本機處理你的照片與 EXIF 中繼資料、選用的安全城市名稱擷取與 iCloud 預設同步運作方式，以及購買與資料管理方式。

無須註冊帳號。所有照片解碼、EXIF 讀取、畫框算繪與 GPS 隱私清除皆在你的裝置本機離線完成；開發者不營運圖片伺服器、不上傳或販售你的照片，且不含廣告或跨 App 追蹤。

1. 照片讀取與本機算繪

當你透過系統照片選擇器、拖放匯入、系統照片分享延伸功能或 Apple 捷徑主動選取照片（含 JPEG、HEIC、RAW/DNG 與原況照片 Live Photo）時，應用程式僅於你的裝置本機讀取影像像素、Display P3 廣色域、Apple HDR 增益圖與 EXIF/TIFF 光學參數，用於即時預覽與無損匯出。

所有影像處理皆於本機記憶體與暫存區完成，照片絕不會上傳至開發者伺服器。儲存時僅依系統相簿權限寫入你的照片圖庫，並清除暫存檔案。

2. GPS 定位清除與選用的安全城市名稱擷取

預設啟用隱私淨化時，匯出成片會自動剝離精確 GPS 經緯度、機身與鏡頭序號、持有人姓名及廠商私有 MakerNote，避免於社群分享時洩露住址或裝置資訊。

應用程式不要求裝置即時定位權限，亦不追蹤行蹤。僅當你在 EXIF 編輯頁主動點擊「僅擷取安全城市名稱作為題註」時，應用程式才會將該照片 EXIF 中的經緯度交由 Apple 系統 CoreLocation 反向地理編碼服務換取城市級名稱，不會傳送給開發者或保留位置紀錄。Apple 服務適用其隱私權政策：https://www.apple.com/legal/privacy/。

3. 本機偏好、手寫簽名與個人 iCloud 預設同步

應用程式於裝置本機及 App Group 共享容器保存收藏模板、排版設定、自訂預設與透明手寫簽名圖檔，供主應用程式與分享延伸功能一致使用。

應用程式支援透過 Apple 個人 iCloud 鍵值儲存（NSUbiquitousKeyValueStore）在你的裝置間同步自訂畫框預設。資料僅存於你個人的 iCloud 帳號，開發者無法存取。你可隨時於系統設定關閉同步，或在應用程式內刪除預設與簽名。

4. 購買與回復

免費版永久提供 3 套經典白框、單張無損匯出與完整 GPS 隱私清除。單次非消耗型 App 內購買（素框 Pro 永久買斷）可解鎖全部 30 套模板、九宮格批次出片、原況照片套框、畫冊拼圖與手寫簽名。

所有付款、權益驗證、回復與退款撤銷狀態皆由 Apple App Store / StoreKit 2 處理，開發者不接觸付款卡資料或 Apple 帳號密碼，適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

5. 主動分享與第三方服務

當你透過系統分享面板將匯出圖片分享至其他應用程式或 AirDrop 時，後續處理適用接收方服務之隱私規則。

本應用程式不含廣告 SDK、行為分析追蹤器或跨 App 追蹤工具，不販售個人資料。本隱私網頁託管於 GitHub Pages，不含廣告、分析指令碼或我們設定的 Cookie；連線紀錄適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. 保存、刪除與聯絡

預設、收藏與簽名圖檔保存在你的裝置與個人 iCloud 空間，刪除應用程式或於 App 內手動刪除即可移除。開發者無伺服器端備份，無法代為存取或復原。
