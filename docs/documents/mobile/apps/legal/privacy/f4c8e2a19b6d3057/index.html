素框 FramePure

隐私政策

生效与更新日期: 2026-11-25
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 应用「素框 FramePure」（含系统相册分享扩展与快捷指令操作）。本政策说明应用如何在设备本地处理你的照片与 EXIF 元数据、可选的城市名提取与 iCloud 预设同步如何工作、应用内购买如何处理，以及你如何管理自己的信息。

无需注册账号。所有照片解码、EXIF 读取、画框渲染与 GPS 隐私擦除均在你的设备本地离线完成，开发者不运营图片服务器，不上传、不收集、不出售你的照片，亦不含广告或跨应用追踪。

1. 照片读取与本地渲染

当你通过系统照片选择器、拖拽导入、系统相册「分享」扩展或 Apple 快捷指令主动选择照片（含 JPEG、HEIC、RAW/DNG 与实况 Live Photo）时，应用仅在你的设备本地读取所选图像的像素、Display P3 广色域、Apple HDR 增益图与 EXIF/TIFF 光学参数，用于实时预览和无损生成相框成片。

所有图像处理均在设备本地内存与临时缓存中完成，照片不会上传至开发者服务器。当你点击保存时，应用经由系统照片图库权限将成片写入你的本地相册，并自动清理渲染过程中产生的临时文件。

2. GPS 定位擦除与可选的安全城市名提取

在默认开启「导出自动抹除 GPS 与设备隐私」的状态下，应用会审计并从导出成片中剥离精确 GPS 经纬度坐标、机身与镜头序列号、持有人姓名及厂商私有 MakerNote，帮助你在社交平台分享作品时避免暴露家庭住址或设备标识。

应用不请求设备实时位置权限，也不追踪你的行踪。仅当你进入 EXIF 编辑页并主动点击「仅提取安全城市名作题注」时，应用才会将当前照片自身 EXIF 中的经纬度交给 Apple 系统 CoreLocation 反向地理编码服务，以换取城市级地名（例如城市名称）供你作为画面题注使用；此过程不会向开发者发送坐标，也不会保存位置历史。Apple 的地理编码服务适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

3. 本地偏好、手写签名与个人 iCloud 预设同步

应用在设备本地及共享应用组（App Group）中保存你的常用模板收藏、当前排版配置、自定义预设及你绘制的透明手写签名图片，以便主应用与系统相册分享扩展保持一致体验。

应用支持使用 Apple 系统提供的个人 iCloud 键值存储（NSUbiquitousKeyValueStore）在你的 iPhone、iPad 与 Mac 之间同步你保存的画框预设配置。这些配置仅保存在你自己的 Apple 账户 iCloud 空间内，不经过开发者服务器，开发者无法读取或访问。你可以在系统 iCloud 设置中随时关闭同步，或在应用内删除预设与签名图片。

4. 购买与恢复

免费版提供 3 套经典白框、单张高清无损导出与完整 GPS 隐私擦除功能。一次非消耗型应用内购买（素框 Pro 永久买断）可解锁全部 30 套画廊与胶片模板、九宫格批量出片、实况 Live Photo 套框、画册拼图及手写签名等功能。

所有购买、付款、恢复与退款/撤销验证均由 Apple 的 App Store / StoreKit 2 服务处理。开发者不会获取你的银行卡信息或 Apple 账户密码。Apple 可能按其服务规则处理交易数据并向开发者提供匿名统计与财务报告，适用 Apple 隐私政策：https://www.apple.com/legal/privacy/。

5. 主动分享与外部服务

当你点击分享按钮将渲染后的成片发送至第三方社交应用或通过隔空投送分享时，内容由你主动选定并交由系统分享面板传递给目标应用，后续处理适用接收方的隐私规则。

本应用不集成任何广告 SDK、行为分析埋点或跨应用追踪框架，不出售个人信息。Apple 可能根据你的设备诊断与分析设置向开发者提供匿名崩溃与性能报告。本隐私网页由 GitHub Pages 托管，不含广告、分析脚本或我们设置的 Cookie；访问网页时 GitHub 可能为保障服务安全记录基础请求日志，适用 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. 数据保存、删除与联系

你的预设、收藏与签名图片保留在你的设备存储及个人 iCloud 空间内；在系统中删除应用会移除设备上的本地数据，你也可随时在应用内删除自定义预设和手写签名。开发者没有服务器端备份，无法代你找回或删除设备上的本地数据。

如果你通过技术支持渠道联系开发者，我们仅在你处理咨询或隐私请求所需的合理期限内使用你主动提供的联系信息与说明，请勿发送隐私原图、密码或完整支付凭据。如有任何隐私疑问或请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「素框 FramePure」。
