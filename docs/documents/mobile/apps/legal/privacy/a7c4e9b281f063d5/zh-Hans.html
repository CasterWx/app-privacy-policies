隐私政策

生效与更新日期: 2026-11-26
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 应用「PurrTouch」（含桌面与锁屏小组件扩展 PurrTouchWidgets）。本政策如实说明应用如何处理本地偏好与陪伴手账数据、如何使用设备陀螺仪与音频能力、如何执行版本更新检测，以及你如何管理自己的本地数据。

无需注册账号，核心体验 100% 本地离线运行。不请求相机、相册、定位、麦克风或通讯录权限；所有猫咪昵称、陪伴手账与偏好仅保存在你的设备本地及私有小组件共享组，开发者不运营用户数据服务器，不含任何广告或跨应用追踪。

1. 本地偏好与陪伴手账数据

为记住你的使用习惯与陪伴记录，PurrTouch 仅在你的设备本地（UserDefaults）保存所选猫咪品种、画风、视角、光影氛围、体格比例、感官与助眠设置，以及你主动输入的猫咪昵称、每日/累计抚摸与呼噜时长、抚摸距离、部位偏好与已解锁的亲密瞬间。

当你添加桌面或锁屏小组件时，应用会通过苹果私有 App Group 容器（group.com.xiaohuwang.purrtouch）在主应用与 PurrTouchWidgets 扩展之间同步轻量快照（当前猫咪、昵称、亲密阶段、性格标签、今日相伴时长与近 7 天节律），所有数据严格停留在你的设备内，不上传至任何服务器。

2. 设备运动传感器、音频与触觉反馈

当你切换至「3D 绒毛」画风时，应用会实时读取设备的 CoreMotion 重力/倾角姿态数据，仅用于在屏幕上呈现柔和的视角微视差效果。姿态数据全程在内存中瞬时计算，绝不记录、存储或发送至设备之外。

应用使用 AVAudioEngine 与 Core Haptics 在设备本地播放内置公有领域猫咪录音、合成窗外环境音并驱动 Taptic Engine 触觉反馈。当你启用助眠定时器时，应用通过系统后台音频能力在锁屏期间持续播放呼噜声与环境音并在最后 60 秒平滑淡出。本应用不请求麦克风权限，不会录制任何声音。

3. 可选版本更新检测与系统评分

为在有新版本发布时提醒你更新，应用在联网状态下至多每 24 小时一次（或由你手动点击「检查更新」时）向 Apple 官方公开接口（itunes.apple.com/lookup）查询 PurrTouch 的线上版本号与商店链接。该请求仅包含应用 Bundle ID 与地区代码，不发送任何个人身份信息、设备标识符或手账内容；离线时静默跳过，不影响正常使用。

在达到自然陪伴里程碑后，应用可能调用 Apple 系统原生评分弹窗（StoreKit AppStore.requestReview），评分交互由 Apple 依据其隐私政策处理，详见：https://www.apple.com/legal/privacy/。

4. 零广告、零第三方追踪与网页托管

PurrTouch 当前完全免费，无内购、无广告，未集成任何广告 SDK、第三方统计分析或跨应用追踪框架，亦不出售或共享任何个人信息。Apple 可能根据你的 iOS 诊断与分析设置向开发者提供匿名汇总的崩溃与性能报告。

本隐私政策网页托管于 GitHub Pages，不含广告、统计脚本或我们设置的 Cookie；访问网页时 GitHub 可能为保障服务安全记录标准服务器访问日志，详见 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

5. 数据保存、删除与联系

你的所有偏好设置、猫咪昵称、陪伴手账与小组件快照均仅保存在你的设备本地存储中。你可随时从系统卸载 PurrTouch 以彻底清除全部本地数据；开发者没有服务器端备份，无法访问、恢复或远程删除你的本地数据。

如对本隐私政策有任何疑问或建议，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「PurrTouch」。请勿在咨询中发送敏感个人凭据。
