もふ猫なで（PurrTouch）

プライバシーポリシー

発効・更新日: 2026-11-26
開発者: Wang xiaohu

本ポリシーは、Wang xiaohu が提供する iOS / iPadOS アプリ「もふ猫なで（PurrTouch）」（ホーム画面・ロック画面ウィジェット拡張機能 PurrTouchWidgets を含む）に適用されます。本アプリにおけるローカル設定やなかよし手帳の保存方法、モーションセンサーとオーディオの利用、バージョン確認の仕組み、およびお客様によるデータ管理方法について説明します。

アカウント登録は不要で、主要な猫なで・安眠体験は 100% 端末内オフラインで動作します。カメラ・写真・位置情報・マイク・連絡先の権限は一切要求しません。猫の名前、なかよし手帳の記録、設定はすべて端末内およびプライベートなウィジェット共有グループのみに保存され、広告やクロスアプリ追跡は一切ありません。

1. ローカル設定となかよし手帳データ

お好みの設定やリラックスの記録を保持するため、本アプリは選択した猫種、画風、視点、窓辺の光、体格比率、触覚・安眠設定、お客様が入力した猫の名前、日別・累計のなで時間やゴロゴロ時間、なで総距離、お気に入りの部位、達成した思い出を端末ローカル（UserDefaults）のみに保存します。

ホーム画面またはロック画面にウィジェットを追加すると、Apple のプライベート App Group コンテナ（group.com.xiaohuwang.purrtouch）を通じて、本体アプリと PurrTouchWidgets 間で軽量なサマリースナップショットのみを共有します。これらのデータが端末外へ送信されることはありません。

2. モーションセンサー・オーディオ・触覚フィードバック

「3D ぬいぐるみ」画風を選択した場合、やわらかな視差表現のために端末内の CoreMotion 重力・傾きセンサー値をリアルタイムに参照します。センサー値はメモリ上で一時的に計算されるのみで、記録・保存・外部送信されることは一切ありません。

本アプリは AVAudioEngine および Core Haptics を用いて、内蔵のパブリックドメイン猫音声の再生、窓辺の環境音のリアルタイム合成、Taptic Engine 触覚フィードバックを端末内で処理します。おやすみタイマー作動中は、ロック画面中もゴロゴロ音と環境音を滑らかにフェードアウト再生するためシステムバックグラウンド音声機能のみを使用します。マイク権限は要求せず、録音は一切行いません。

3. 任意のバージョン更新確認とシステム評価

新バージョンの公開をお知らせするため、オンライン時に最大 24 時間に 1 回（またはお客様が手動で「アップデートを確認」をタップした際）、Apple 公式公開エンドポイント（itunes.apple.com/lookup）へ本アプリの Bundle ID と地域コードのみを用いて最新バージョン情報を照会する場合があります。個人情報・端末識別子・手帳内容は一切送信されず、オフライン時は静かにスキップされます。

自然な利用マイルストーン到達後、Apple ネイティブの評価ダイアログ（StoreKit AppStore.requestReview）を表示する場合があります。評価処理は Apple のプライバシーポリシー（https://www.apple.com/legal/privacy/）に従って取り扱われます。

4. 広告・第三者トラッキングなし、およびページ配信

本アプリには広告、第三者アナリティクス SDK、クロスアプリ追跡フレームワークは一切含まれておらず、個人データの販売や共有も行いません。お客様の iOS 診断・解析設定に基づき、Apple から匿名集計されたクラッシュおよびパフォーマンスレポートが開発者に提供される場合があります。

本プライバシーポリシーページは GitHub Pages で配信されており、広告、解析スクリプト、当方設定の Cookie は含みません。アクセス時の標準サーバーログについては GitHub プライバシーステートメント（https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement）をご確認ください。

5. データの保持・削除およびお問い合わせ

すべての設定、猫の名前、なかよし手帳、ウィジェットスナップショットはお客様の端末内のみに保存されます。iOS / iPadOS から本アプリを削除することで、すべてのローカルデータが完全に消去されます。開発者はサーバー上にバックアップを保持しないため、遠隔での閲覧・復元・削除はできません。

プライバシーに関するご質問やご要望は、サポートサイト https://ai-topic.cn より「もふ猫なで（PurrTouch）」と明記のうえ開発者 Wang xiaohu までお問い合わせください。
