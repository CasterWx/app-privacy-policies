摸了個貓（PurrTouch）

隱私權政策

生效與更新日期: 2026-11-26
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS / iPadOS 應用程式「摸了個貓」（PurrTouch）（含桌面與鎖定畫面小工具延伸功能 PurrTouchWidgets）。本政策說明應用程式如何於本機保存偏好設定與陪伴手帳、如何使用裝置動作感測器與音訊能力、如何檢查版本更新，以及你如何管理本機資料。

無須註冊帳號，核心體驗 100% 於裝置本機離線運作。不要求相機、相簿、定位、麥克風或聯絡人權限；所有貓咪暱稱、陪伴手帳與偏好皆僅存於你的裝置本機及私有小工具共享群組，開發者不營運資料伺服器，亦不含任何廣告或跨 App 追蹤。

1. 本機偏好與陪伴手帳資料

為記住你的習慣與陪伴紀錄，PurrTouch 僅於裝置本機（UserDefaults）保存所選貓咪品種、畫風、視角、光影氛圍、體格比例、感官與助眠設定，以及你自行輸入的貓咪暱稱、每日與累計撫摸／呼嚕時長、撫摸距離、部位偏好與已解鎖的親密瞬間。

當你加入桌面或鎖定畫面小工具時，應用程式透過 Apple 私有 App Group 容器（group.com.xiaohuwang.purrtouch）在主程式與 PurrTouchWidgets 之間同步輕量摘要快照，所有資料皆嚴格留存在你的裝置內，絕不上傳至任何伺服器。

2. 裝置動作感測器、音訊與觸覺回饋

切換至「3D 絨毛」畫風時，應用程式僅於本機即時讀取 CoreMotion 重力與傾角資料以呈現柔和視差，數據於記憶體內即時計算，絕不記錄、儲存或傳出裝置。

應用程式使用 AVAudioEngine 與 Core Haptics 於本機播放內建公有領域貓咪錄音與即時合成窗外環境音，並於開啟助眠定時器時透過系統背景音訊於鎖定畫面平緩淡出。本應用程式不要求麥克風權限，絕不錄製任何聲音。

3. 選用版本檢查與系統評分

為提醒新版本發佈，應用程式於聯網狀態下至多每 24 小時一次（或由你手動點擊檢查更新時）向 Apple 官方公開介面（itunes.apple.com/lookup）查詢 PurrTouch 版本資訊，僅傳送 Bundle ID 與地區代碼，不含任何個人識別資料；離線時靜默略過。

達成自然陪伴里程碑後，應用程式可能呼叫 Apple 原生評分視窗（StoreKit AppStore.requestReview），適用 Apple 隱私權政策：https://www.apple.com/legal/privacy/。

4. 零廣告、零追蹤與網頁託管

PurrTouch 無廣告、未整合任何第三方分析或跨 App 追蹤框架，亦不販售或分享個人資料。Apple 可能依你的系統設定提供匿名彙總之當機與效能診斷。

本隱私權網頁託管於 GitHub Pages，不含廣告、統計指令碼或我們設定的 Cookie；連線紀錄適用 GitHub 隱私聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

5. 資料保存、刪除與聯絡

所有偏好、貓咪暱稱、陪伴手帳與小工具快照皆僅保存於你的裝置本機。卸載 PurrTouch 即可徹底移除全部本機資料；開發者沒有伺服器端備份，無法遠端存取或復原你的資料。

如有任何隱私問題，請透過技術支援網址 https://ai-topic.cn 聯絡開發者 Wang xiaohu，並註明「PurrTouch」。
