AfterCaff（余因）

プライバシーポリシー

発効・更新日: 2026-11-26
開発者: Wang xiaohu

本ポリシーは、Wang xiaohu が提供する iOS / iPadOS / watchOS アプリ「AfterCaff（余因）」（ウィジェット、ライブアクティビティ、コントロールセンター、ショートカット、Apple Watch アプリを含む）に適用されます。端末内でのデータ保存、Apple ヘルスケア連携、オフライン Vision OCR、iCloud 同期、アプリ内課金の取り扱いについて説明します。

アカウント登録は不要です。カフェイン記録、代謝設定、カスタムレシピ、朝の睡眠チェック、レシート OCR はすべて端末内で処理・保存され、同期はご自身の Apple iCloud キー値ストレージのみを使用します。広告・追跡 SDK は一切含みません。

1. 端末内保存および Apple Watch 連携

記録したドリンク名、カフェイン量、摂取時刻、サイズ、ゆっくり飲み時間、価格、体感タグ、朝の睡眠チェック、カスタムレシピ、代謝パラメータは、端末内の SwiftData データベースおよび App Group コンテナに保存され、ウィジェットやショートカットと安全に共有されます。

Apple Watch との同期には Apple WatchConnectivity を使用し、iPhone と Apple Watch 間で直接データをやり取りします。開発者サーバーを経由することはありません。

2. Apple ヘルスケア（HealthKit）双方向連携

ユーザーが明示的に許可した場合に限り、AfterCaff は Apple ヘルスケアの睡眠分析データ（深い睡眠・レム睡眠・コア睡眠）を読み取って就寝前カフェインとの相関を端末内で分析し、記録したカフェイン摂取量を「カフェイン」として書き込みます。

Apple HealthKit ガイドラインを厳格に遵守し、ヘルスケアデータを外部サーバーへ送信したり、広告・マーケティング・第三者提供に利用することは一切ありません。権限は iOS の「設定 → ヘルスケア」からいつでも変更・解除できます。

3. オフライン Vision OCR・カメラ・写真アクセス

レシートや注文スクリーンショットの読み取りはすべて端末上の Apple Vision OCR エンジンでオフライン実行されます。画像や認識テキストが外部サーバーに送信されることはなく、元画像も保存しません。

週間ポスターを写真ライブラリに保存する際は書き込み権限のみを使用し、他の写真へアクセスすることはありません。

4. 個人 iCloud 同期とローカル通知

同一 Apple Account の端末間同期には Apple の NSUbiquitousKeyValueStore を使用します。データはお客様自身の iCloud 領域にのみ保管され、開発者はアクセスできません。

最終コーヒー締切リマインダーは端末内の UNUserNotificationCenter によるローカル通知のみで動作します。

5. サブスクリプション・買い切り購入と復元

基本的な代謝カーブ、116種以上のドリンク図鑑、2杯比較 PK、オフライン OCR、7日間レポート、ヘルスケア連携は無料で利用できます。AfterCaff Pro（年間自動更新サブスクリプションまたは買い切り）により、30日間レポート、無制限カスタムレシピ、全ポスターテーマ、4種の限定アイコンが解放されます。

決済・更新・復元・返金処理はすべて Apple App Store / StoreKit 2 が担当し、Apple プライバシーポリシー（https://www.apple.com/legal/privacy/）が適用されます。

6. 第三者 SDK・免責事項・お問い合わせ

広告 SDK や行動追跡ツールは一切組み込んでいません。本ページは GitHub Pages で配信されており、アクセスログには GitHub プライバシーステートメント（https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement）が適用されます。

本アプリの代謝予測は一般的な薬物動態モデルに基づく健康参考値であり、医療機器や医療アドバイスではありません。CSV 書き出しや記録削除はアプリ内でいつでも行えます。プライバシーに関するお問い合わせは https://ai-topic.cn より「AfterCaff」と明記のうえ開発者 Wang xiaohu までご連絡ください。
