隐私政策

生效与更新日期: 2026-11-26
开发者: Wang xiaohu

本政策适用于 Wang xiaohu 提供的 iOS / iPadOS 应用「清一清相册」（英文名 CleanRoll，含桌面小组件与灵动岛实时进度扩展）。本政策说明应用如何在你的设备本地离线扫描整理相册、压缩视频与图片、如何处理照片元数据与本地缓存、如何处理应用内购买，以及你如何管理自己的信息。

无需注册账号，100% 本地离线运行。所有相似连拍识别、模糊废片筛选、视频硬件压制、图片格式转换与实况照片处理均在你的设备端完成；开发者不运营任何媒体服务器，不上传、不收集、不出售你的照片或视频，亦不含任何广告或跨应用追踪。

1. 相册访问与本地离线分析

经你授予系统照片图库权限后，应用仅在你的设备本地读取相册中的照片、实况照片与视频（全程设置仅限本机离线读取，不主动发起云端下载或向开发者上传数据），利用 Apple Vision 视觉框架、清晰度评估与像素摘要算法在设备端识别完全重复项、相似连拍、模糊废片、旧截图与超大视频。

你在滑卡或列表中标记待清理的素材会先进入应用内的「暂存箱」，不会在未确认的情况下删除任何内容。只有当你主动点击最终清理并通过 Apple 系统删除弹窗确认后，系统才会将所选项目移入 iOS「最近删除」相册（30 天内可随时恢复）。

2. 视频压缩、图片转换与元数据隐私保护

应用内的精密瘦身暗房使用 Apple 硬件 VideoToolbox、AVFoundation 与 ImageIO 引擎在设备本地完成视频倒推码率压制、HDR 转 SDR 映射、3 秒试压对比、图片指定体积压缩（HEIF / JPEG / PNG）及实况照片转视频或动图，所有临时文件仅保存在设备本地沙盒并在完成后清理。

应用不请求设备实时定位权限，也不追踪你的位置。按地点整理的滑卡分组仅将照片自身已包含的坐标与设备内置的离线城市坐标表进行本地比对，不发起联网地理编码请求。在瘦身导出时，你可选择保留原拍摄日期与地点，或开启「剥离隐私 GPS 定位与设备 EXIF」以在分享前清除位置与设备信息。

3. 本地缓存、小组件共享组与灵动岛

为加速后续扫描并保持整理进度，应用仅在你的设备本地存储扫描特征摘要缓存、白名单与收藏保护开关、已暂存与已阅记录、累计释放空间统计，并通过私有 App Group 容器（group.com.xiaohuwang.cleanroll）向你添加的桌面小组件同步「历史上的今天」计数、可释放空间摘要与单张低分辨率本地缩略图。

批量压制视频时，应用使用 Apple ActivityKit 在锁屏与灵动岛本地展示实时压制进度与速率，不向外部推送服务器发送任何照片或文件名。

4. 购买与恢复

应用免费提供体验清理额度（最多 100 项或累计 500 MB），无广告、无强制订阅。一次非消耗型应用内购买（「清一清相册 Pro」永久买断，产品 ID：com.xiaohuwang.cleanroll.pro.lifetime）可永久解锁无限清理额度、全部智能筛选与瘦身功能。

所有付款、权益验证、恢复购买与退款状态均由 Apple App Store / StoreKit 2 处理。开发者不会获取你的银行卡信息或 Apple 账户密码。Apple 按其隐私政策处理交易并可能向开发者提供匿名汇总财务报告，详见 Apple 隐私政策：https://www.apple.com/legal/privacy/。

5. 主动分享与第三方服务

当你主动点击分享按钮将压制后的视频、图片或清理战报海报发送至微信、隔空投送或其他第三方应用时，内容由你通过系统分享面板交由目标应用处理，后续行为适用接收方自身的隐私政策。

本应用不集成任何广告 SDK、第三方统计埋点或跨应用追踪框架，不出售个人信息。Apple 可能根据你的系统诊断与分析设置向开发者提供匿名崩溃与性能日志。本隐私政策网页托管于 GitHub Pages，不含广告、统计脚本或我们设置的 Cookie；访问网页时 GitHub 可能为保障服务安全记录标准请求日志，详见 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。

6. 数据保存、删除与联系

你的所有偏好设置、本地特征缓存与小组件摘要均仅保存在你的设备存储中。你可以在应用内随时清空暂存箱或重置白名单，或直接从系统中卸载应用以彻底清除全部本地数据。开发者没有服务器端备份，无法访问、代为找回或远程删除你的本地数据。

如你对本隐私政策有任何疑问或请求，请通过技术支持网址 https://ai-topic.cn 联系开发者 Wang xiaohu，并注明涉及「清一清相册（CleanRoll）」。请勿在咨询中发送隐私原图、密码或完整支付凭据。
