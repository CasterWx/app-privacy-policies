碰草門禁 · TouchGate

隱私權政策

生效與更新日期: 2026-11-26
開發者: Wang xiaohu

本政策適用於 Wang xiaohu 提供的 iOS 應用「碰草門禁（TouchGate）」（含桌面小工具、動態島以及 Apple 螢幕使用時間監控與攔截擴充功能）。本政策說明應用如何在裝置本機使用螢幕使用時間權限、端側相機視覺偵測、運動步數感測、近場標籤讀取與本機通知，以及你如何管理或刪除自己的資料。

無需註冊帳號，100% 端側本機執行。你的應用鎖定選擇、相機姿態與戶外草地辨識、步數統計、NFC 標籤綁定、打卡紀錄與可選實拍標本照片均嚴格在你的 iPhone 本機處理與儲存；開發者不營運任何使用者伺服器，不收集、不上傳、不出售你的任何個人資料，亦不含廣告或跨應用追蹤。

1. 本機紀錄、規則設定與系統擴充共享

你在應用內設定的門禁規則、打卡紀錄、成就解鎖狀態以及已綁定的實體錨點資訊，均僅儲存在你的裝置本機與系統共享應用群組（App Group）容器中，以維持主應用、小工具、動態島與螢幕使用時間擴充的狀態一致。

本應用無雲端帳號系統，所有資料均不經過開發者伺服器。

2. Apple 螢幕使用時間（FamilyControls）權限

僅在你主動授權 Apple「螢幕使用時間」權限並自行選取應用或分類後，碰草門禁才會對所選應用施加本機攔截，並在完成實體挑戰後提供臨時放行與到期自動重鎖。

依 Apple 系統隱私機制，所選應用僅以系統加密不透明權杖（Opaque Token）存於本機，開發者無法讀取你的已安裝應用清單或使用明細，亦不會向外傳輸。你可隨時於系統「設定 → 螢幕使用時間」撤回授權。

3. 端側相機、戶外實拍標本與防作弊校驗

當你進行「運動計數」、「出門摸草」或「條碼掃描」挑戰時，相機畫面僅於裝置記憶體內透過 Apple Vision 即時本機分析，絕不錄影、絕不上傳任何伺服器。

「出門摸草」通關時，應用可於本機沙盒保存一張壓縮實景照片供「摸草標本牆」與你主動分享的「摸草證明卡」使用，你隨時可在「規則 → 清空本機紀錄」中一鍵刪除。

4. 運動與健身（步數與微動）及近場標籤（NFC）

進行「起身走步」或「出門摸草」防翻拍校驗時，應用僅在挑戰進行期間透過 Apple CoreMotion 讀取本機即時步數與手持微動訊號，挑戰結束立即停止，不讀取歷史健康檔案，亦不上傳資料。

綁定或輕觸 NFC 貼紙時，應用僅透過 Apple CoreNFC 在本機比對標籤編號，不向外傳送資訊。

5. 應用內購買（碰草門禁 Pro 終身買斷）與恢復購買

核心實體門禁與基礎解鎖功能免費提供。應用提供一次性非消耗型內購「碰草門禁 Pro（終身買斷）」，用於解鎖同日魔鬼加碼、防反悔規則鎖、防解除安裝保護、睡前與工作自動排程、全部運動姿勢及史詩/傳說收藏卡高畫質匯出。

所有付款、驗證、恢復購買與退款/撤銷狀態同步均由 Apple App Store / StoreKit 2 處理，開發者不取得你的付款卡資訊或 Apple 帳號密碼。Apple 依其隱私權政策（https://www.apple.com/legal/privacy/）處理交易並可能向開發者提供交易通知及銷售統計報告。

6. 本機通知、第三方 SDK 與資料管理

所有提醒均由本機通知中心觸發，無遠端推播伺服器；分享海報由本機即時繪製並僅在你點擊分享時交由 iOS 系統分享面板處理。

本應用不整合任何廣告 SDK、分析埋點或跨應用追蹤框架。本隱私網頁託管於 GitHub Pages，適用 GitHub 隱私權聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。你隨時可在應用內清空資料或解除安裝移除全部本機資料，如有疑問請透過 https://ai-topic.cn 聯繫 Wang xiaohu 並註明「碰草門禁（TouchGate）」。
