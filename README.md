# Application Documents

Static documents distributed through application-specific links.

Please use the document URL provided in the app or its store listing.

应用相关文件通过专用网址提供。请使用应用或商店页面提供的文件链接。

## Maintenance

```sh
python3 scripts/build.py
```

Generated files are served from `docs/`. No application directory or document links are published on the landing page.
